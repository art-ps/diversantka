## Минор (отложено)

- `levels.test.ts`: заглушка `expect(DT).toBeGreaterThan(0)` (мандат плана).
- `missionDef`/`worldOf` не проверяют, что n — целое ≥ 1 (от ссылки защищает `unpackReplay`).
- Забор включается по `missionId >= 3`, а не по `goal === 'tapes'` (зависит от шаблонов).
- `become()`: комментарий «открытая миссия 2» устарел.

- `saveLevel` может понизить уровень, если `getItem` бросил, а `setItem` сработал.

- Путь `replayOld` → `main.ts` не покрыт тестом (`main.ts` не тестируется; откат при ошибке `startMission` — тоже).
- RED-доказательства в плане 6.2 — только текстом.

## Для 6б (босс), по спеке «6б — босс»

- Цель `boss` на N = 10, 20, 30…; уровень как обычный, целевая комната — шаблон с тегом `arena`: один экран, ровный пол, 2 платформы `=` по бокам, без воды и шипов; вход за последней дверью. Пока босс жив, проём закрыт решёткой `A`; убит — поднята. Мотоцикл в стартовой, выезд только после смерти босса.
- Текст задачи `УНИЧТОЖЬ АНДРОИДА` / `DESTROY THE ANDROID`.
- Босс: скелет андроида ×1.5, `PAL.boss`, полоса HP над ареной, HP `8 + 4 × (N / 10 − 1)`; веер из 3 ножей (одна высота пропущена); прыжок с ударной волной `^` (урон 20); ближний удар с телеграфом 0.4 с; цикл веер → пауза → прыжок → пауза; ярость с половины HP (паузы ×0.6); неуязвимость 0.5 с; смерть — частицы, `explode`, решётка поднята; гибель героини — откат к чекпоинту, HP босса полное. Числа — `BOSS` в `config.ts`, строки — RU/EN.
- Точки в коде: `goalOf` в `src/gen/difficulty.ts` (сейчас bomb/tapes по чётности — добавить `boss` для кратных 10); тег шаблона `arena`; `goalLine` (шаг `boss`); `missionName(n, 'boss')` = `АНДРОИД` / `ANDROID`; `titleTaskGen(goal, tapes, minutes)` — ветка `boss`; легенда карты (`Б` / `B` — арена).
- Таймер: сгенерированные уровни уже доходят до ~34:30 к уровню 30 — свои лимиты не вводить.
